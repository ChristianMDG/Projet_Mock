# 📝 Couverture d'Assurance

## Composant : Couverture d'Assurance

### 🇫🇷 Français (Locale par défaut)

**Titre de la section :** `Nos assurances pour votre protection`

#### Assurance 1 : Responsabilité Civile (RC)
```
Nom : Responsabilité Civile (RC)
Description : Assurance obligatoire couvrant les dommages causés aux tiers lors d'un accident. Cette assurance protège tous les passagers en cas de collision.
Couverture : Dommages corporels et matériels aux tiers - Plafond : 50 000 000 Ar
Inclus : Oui (incluse dans le prix du billet)
Prix : Inclus
```

#### Assurance 2 : Tous Risques
```
Nom : Assurance Tous Risques
Description : Protection complète couvrant tous les types de dommages, y compris le vol, l'incendie, les catastrophes naturelles et les accidents corporels des passagers.
Couverture : Dommages au véhicule, vol, incendie, catastrophes naturelles, accidents corporels - Plafond : 100 000 000 Ar
Inclus : Oui (incluse dans le prix du billet)
Prix : Inclus
```

#### Assurance 3 : Assurance Bagages
```
Nom : Assurance Bagages
Description : Protection de vos bagages contre la perte, le vol ou les dommages pendant le transport. Indemnisation rapide en cas de sinistre.
Couverture : Perte, vol ou dommages des bagages - Plafond : 500 000 Ar par passager
Inclus : Non (optionnelle)
Prix : 2 000 Ar par trajet
```

#### Assurance 4 : Assurance Annulation
```
Nom : Assurance Annulation
Description : Remboursement de votre billet en cas d'annulation pour motif valable (maladie, urgence familiale, catastrophe naturelle). Souscrivez lors de la réservation.
Couverture : Remboursement jusqu'à 100% du prix du billet selon le motif
Inclus : Non (optionnelle)
Prix : 5% du prix du billet
```
